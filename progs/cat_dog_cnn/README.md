# Cat vs Dog CNN

Этот проект показывает, как на практике обучить простую сверточную нейронную сеть для распознавания изображений котов и собак с помощью PyTorch.

Цель проекта — не просто получить модель, а понять, как устроен полный цикл:

- подготовка данных;
- преобразование изображений в тензоры;
- обучение CNN;
- проверка качества на валидации и тесте;
- сохранение лучшей модели.

---

## Что здесь происходит

Проект использует датасет с картинками двух классов:

- Cat
- Dog

Модель принимает изображение на вход, проходит через несколько сверточных слоёв, извлекает признаки и на выходе выдаёт вероятность принадлежности к одному из двух классов.

## Что делают преобразования изображений

В коде используется `transforms.Compose(...)`:

```python
transform = transforms.Compose([
    transforms.Resize((64, 64)),
    transforms.ToTensor(),
    transforms.Normalize((0.5,), (0.5,))
])
```

### 1. Resize

`Resize((64, 64))` делает все изображения одинакового размера. Это важно, потому что нейронная сеть ожидает вход фиксированной формы.

Почему это нужно:

- все картинки становятся одного формата;
- обучение проходит стабильнее;
- сеть работает быстрее, чем если бы мы подавали большие изображения вроде 1920×1080.

### 2. ToTensor

`ToTensor()` переводит изображение из формата PIL/PNG в тензор PyTorch.

Кроме того, значения пикселей приводятся к диапазону от 0 до 1:

- старый диапазон: от 0 до 255;
- новый диапазон: от 0 до 1.

Это делает обучение нейросети более удобным и устойчивым.

### 3. Normalize

`Normalize((0.5,), (0.5,))` центрирует данные вокруг нуля и делает их более «нейросетевыми» по масштабу.

Формула выглядит так:

```text
(x - mean) / std
```

То есть значения становятся примерно в диапазоне от -1 до 1.

Это помогает сети обучаться быстрее и лучше.

## Что такое ImageFolder и DataLoader

### ImageFolder

`datasets.ImageFolder(...)` — это удобный способ загрузить данные, если изображения уже лежат в папках по классам.

Каждый элемент датасета возвращает:

- изображение в виде тензора;
- метку класса, например `0` для Cat и `1` для Dog.

### DataLoader

`DataLoader` берёт данные из датасета и отдаёт их батчами.

Например, `batch_size=32` означает, что за одну итерацию сеть получает не одну картинку, а сразу 32.

Это ускоряет обучение и делает его более стабильным.

## Как устроена нейронная сеть

В проекте используется простая CNN с тремя сверточными слоями.

### Основные блоки

- `Conv2d` — сверточные слои, которые ищут признаки на изображении;
- `ReLU` — функция активации, добавляющая нелинейность;
- `MaxPool2d` — уменьшает размер карты признаков и помогает выделять самые важные признаки;
- `Linear` — полносвязные слои, которые делают финальное решение: кот или собака.

### Почему это работает

Сверточные слои учатся распознавать простые паттерны:

- края;
- углы;
- текстуры;
- более сложные формы на следующих слоях.

Постепенно сеть начинает понимать, что отличает кота от собаки.

## Что такое `in_channels`, `out_channels` и `kernel_size`

### `in_channels`

Это количество входных каналов изображения.

Для RGB-изображения это обычно `3`:

- красный канал;
- зелёный канал;
- синий канал.

### `out_channels`

Это количество фильтров в слое.

Каждый фильтр создаёт свою карту признаков.

### `kernel_size`

Размер фильтра, который «скользит» по изображению.

Например, `kernel_size=3` означает, что фильтр имеет размер `3×3`.

## Как идёт обучение

Обучение происходит поэтапно:

1. модель получает батч изображений;
2. делает предсказания;
3. сравнивает их с правильными метками;
4. считает ошибку;
5. обновляет веса с помощью обратного распространения ошибки.

### Валидация

После каждой эпохи модель проверяется на валидационном наборе.

Важно: на валидации веса не обновляются. Она нужна, чтобы понять:

- улучшилась ли модель;
- не произошло ли переобучение.

### Early stopping

В коде есть механизм ранней остановки обучения:

- если качество на валидации не улучшается несколько эпох подряд, обучение прекращается.

Это помогает не тратить лишнее время.

## Как запустить проект

### Установите зависимости

```bash
pip install torch torchvision pillow
```

### Подготовьте данные

Убедитесь, что у вас есть папки:

```text
dataset/train/Cat
Dataset/train/Dog
```

и аналогично для `val` и `test`.

### Запустите обучение

```bash
python train.py
```

Во время обучения будут выводиться:

- loss;
- точность на обучении;
- точность на валидации.

В конце будет сохранена лучшая модель в файл `best_model.pth`.

## Кратко о главных идеях

- изображения нужно привести к одинаковому размеру;
- нейросеть работает с числами, поэтому изображения превращаются в тензоры;
- CNN умеет извлекать признаки прямо из картинки;
- обучение идёт по батчам;
- валидация нужна для контроля качества;
- лучшая модель сохраняется для дальнейшего использования.
