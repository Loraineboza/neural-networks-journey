
Файлы regr_train и trainprop содержут справочную информацию по использованию продвинутой техники валидации  вычислению качества
модели относительно с предыдущим критерием ошибки на незнакомых 
данных (это выполняет ф-я calculate accuracy)
---
**regr_train - трейнинг регрессии на основе чекпоинтов модель (сохраняется 
вся стукрутра модели. Не только веса и смещения) с выбором лучшего
показателя критерия**

**trainprop - основа пропорции данных , где настривается 
нормализованное распределение сигналов , где std=N, mean=N**
