Здесь содержится упражнения и примеры из обучающих материалов по PyTorch: [runebook](https://runebook.dev/ru/docs/pytorch)

1. Тензорные Структуры Данных:
  Инициация и манипуляция тензорами: Демонстрация процедур создания многомерных массивов и последующих операций над ними.
  Фундаментальные арифметические действия: Реализация базовых вычислительных процессов, включая поэлементное суммирование, матричное умножение и трансформацию размерностей (изменение формы).
  Практическое применение: Интеграция тензорных вычислений в контексте задач машинного обучения.

2.  Системы Управления Данными: Наборы Данных и Загрузчики
Интеграция встроенных коллекций: Эксплуатация предустановленных датасетов, например, FashionMNIST, для быстрого прототипирования.
Конструирование кастомных наборов: Разработка пользовательских классов Dataset для обработки структурированных данных из CSV-форматов.
Оптимизация загрузочных процессов: Применение механизма DataLoader для обеспечения эффективной пакетной подачи данных и параллельной обработки.

3. Преобразовательные Процедуры
Геометрическая адаптация изображений: Реализация операций ресайзинга, кадрирования и нормализации пиксельных значений.
Разработка пользовательских трансформаций: Создание специализированных преобразований, включая стохастическое горизонтальное отражение (flip).
Композиция трансформационных цепочек: Объединение множественных преобразований в последовательные пайплайны с использованием Compose

4. Автоматическое Дифференцирование (Автоград)
Градиентное исчисление: Автоматизированное вычисление производных как для скалярных, так и для векторно-значных функций.
Матрица Якоби и производные высших порядков: Вычисление матриц частных производных и реализация механизмов для получения производных старших порядков.
Управление градиентным потоком: Демонстрация техник отслеживания (tracking) и принудительного отсоединения (detaching) градиентов от вычислительного графа.

5. Оптимизационные Алгоритмы
Минимизация целевых функций: Применение метода градиентного спуска для нахождения локальных и глобальных экстремумов.
Специализированная оптимизация: Решение задач минимизации квадратичных форм и функций расстояния с использованием встроенных оптимизаторов PyTorch (SGD, Adam и др.).
